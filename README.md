# Ôn tập Tiếng Anh 2 (Global Success, học kỳ 1)

Web tĩnh một file, tranh đã nhúng sẵn. Mở `index.html` bằng Chrome hoặc Edge.

## Đưa lên GitHub Pages
1. Tạo repository mới, tải 3 file `.nojekyll`, `index.html`, `README.md` lên nhánh `main`.
2. Vào Settings > Pages, chọn Branch `main`, thư mục `/ (root)`, bấm Save.
3. Sau ít phút trang chạy tại `https://<tên-tài-khoản>.github.io/<tên-repo>/`.
